# sdd-skill

Скилл для Claude Code, который ведёт разработку целиком — от размытой идеи до влитых тикетов: реализацию делают субагенты, контроль остаётся у человека.

*[Read in English](README.md)*

## Что это

Ты описываешь, чего хочешь. Дальше скилл ведёт интервью, пока в дереве решений не останется ни одной ветки, где что-то предполагается молча; пишет спеку в трекер; режет её на трассирующие ломтики; на каждый тикет запускает свежего агента в отдельной рабочей копии; вливает линейно; и держит документ передачи свежим, чтобы исчерпанный контекст ничего не стоил.

Это намеренно **не** кнопка «построй мне продукт, пока я сплю». Каждая продуктовая развилка — вопрос с одной рекомендацией; каждый вкусовой вопрос решается взглядом на макет; каждое слияние координатор проверяет своими командами, а не верит отчёту исполнителя на слово.

## Это надстройка, а не замена

Скилл управляет набором **mattpocock-skills** (`ask-matt`, `to-spec`, `to-tickets`, `implement`, `tdd`, `code-review`, `grilling`, `domain-modeling`). Там описан сам поток; здесь — как вести его агентами и с человеком в контуре. Ставить надо оба: скилл считает, что плагин на месте.

## Рядом, по пунктам

Ничего из левой колонки не заменяется — скилл её вызывает.

| | Набор mattpocock | Эта надстройка |
|---|---|---|
| **Кто пишет код** | Ты, в своей сессии, `/clear` между тикетами | Фоновые исполнители по одному на тикет; появляется отдельная роль — координатор |
| **Рабочая копия** | Одна, работа последовательная | Своя worktree каждому, включая того, кто по смыслу «работает в целевой ветке» |
| **Параллельность** | Не нужна — некому параллелиться | Фронтир пересчитывается после каждого слияния; параллельно идут только тикеты без общих файлов |
| **Приём работы** | `code-review` внутри `implement` — ты и есть автор | Координатор перепроверяет утверждения отчёта своими командами и делит расхождения на три корзины: принято / оператору / красная полоса |
| **Слияние** | Обычная работа с ветками | Только линейное: `rebase` → `--ff-only`; уехавшая база переносится `rebase --onto` по хешу, записанному в момент переклада |
| **Обрыв исполнителя** | Нет такого случая | Его незакоммиченные файлы — ценность: попадают в передачу и передаются следующему со словами «продолжай черновик, а не переписывай» |
| **Передача** | `/handoff` — ручное сжатие текущего разговора в файл во временной папке ОС, вызывается человеком | Документ в репозитории, заводится **до** первого исполнителя и обновляется после каждого слияния; хук подаёт голос, когда он отстал от кода |
| **Интервью** | `grill-with-docs` — механика грилла, `CONTEXT.md` и ADR | Форма раунда с живым человеком: одна рекомендация на вопрос, «ок» принимает весь раунд, вкус решается макетом, факты добываются до вопроса |
| **Операционка** | Не его слой | Разрешение раз на класс действий, учётные данные не в переписке, экзит-код читается в одиночку, пересечения репозиториев через scratchpad |

Работаешь один в одной сессии — **набора Мэтта достаточно**, и он дешевле. Надстройка окупается там, где веха длиннее одной сессии и реализацию отдают агентам.

Чего здесь **нет** и что остаётся за набором Мэтта: разбор входящих задач, дебаг, прототипы, мастера установки, конфликты слияния и `wayfinder` для задач, которые ещё не удаётся охватить целиком.

## Чем это отличается от «попроси агента сделать»

Каждый пункт ниже — шрам, а не вкусовщина:

- **Одна рекомендация на вопрос, никакого меню.** Раунд принимается одним «ок»; несогласие — это назвать номер.
- **Факты координатор добывает сам, до вопроса.** Всё, что можно посмотреть в файлах, коде и документации, смотрится первым; исследование первоисточников идёт фоновым агентом, пока раунды продолжаются.
- **Вкус решается глазами.** Раскладка, палитра и тон — по настоящему макету в настоящих токенах проекта, с таблицей различий в числах. Вкусовые вопросы не отдаются субагентам: субагент не покажет картинку и не услышит «слишком мрачно».
- **Своя рабочая копия каждому исполнителю**, включая того, кто по смыслу «работает в основной ветке». Это снимает три беды разом: перемешанные `git add`, гонку за одними файлами и погашенные чужие процессы.
- **Живая передача.** У Мэтта есть `/handoff`, но он сжимает текущий разговор в файл во временной папке, когда его об этом попросят. Здесь другой жанр: документ в репозитории, заведённый до первого исполнителя и обновляемый после каждого слияния, плюс хук, который подаёт голос, когда документ отстал. Лимит модели и закрытый терминал приходят без предупреждения; свежая передача делает их бесплатными.
- **Слияние только линейное** (`rebase`, затем `--ff-only`), а когда база исполнителя уехала — `rebase --onto <целевая> <старый tip блокера> <его ветка>`, причём старый хеш записывается в передачу в момент переклада, а не ищется потом в reflog.
- **Незакоммиченные файлы упавшего исполнителя — ценность, а не мусор.** Они попадают в передачу и передаются следующему агенту со словами «продолжай черновик, а не переписывай».
- **Экзит-код читается в одиночку.** Команда, чей код возврата и есть ответ, запускается без хвоста `; echo; tail` — иначе оболочка отчитается об успехе хвоста, и упавший выпуск прочитается как зелёный. Это уже случалось.
- **Разрешение спрашивается один раз на класс действий и записывается.** Пуш, релиз, выкатка, перезапуск — получив разрешение, координатор делает их сам, а не возвращает человеку рутину. За человеком остаются продуктовые решения и то, где нужны лично его учётные данные.
- **Учётные данные не запрашиваются в переписке никогда.** Секрет вводится там, где он читается, — из stdin или из формы. Появился в переписке — координатор говорит об этом прямо и советует ротацию.
- **Приёмка идёт той же дверью, в которую входит пользователь.** Зелёные тесты не доказывают, что продукт работает; матрица платформ — часть этой двери.

## Установка

```bash
# 1. набор, которым управляет скилл
claude plugin marketplace add anthropics/claude-plugins-official
claude plugin install mattpocock-skills@claude-plugins-official

# 2. сам скилл
git clone https://github.com/IulaiJedi/sdd-skill ~/.claude/skills/sdd
```

Дальше в сессии — `/sdd` или просто «сделай по SDD».

### Необязательно: хук свежести

`handoff-stale.sh` напоминает обновить передачу, когда она отстала от кода. Молчит везде, кроме git-репозитория, где действительно лежит `docs/handoff-*.md`; любая неожиданность — тихий выход. Он напоминает, а не мешает. В `~/.claude/settings.json`:

```json
{
  "hooks": {
    "Stop": [
      { "hooks": [ { "type": "command", "command": "~/.claude/skills/sdd/handoff-stale.sh" } ] }
    ],
    "PreCompact": [
      { "hooks": [ { "type": "command", "command": "~/.claude/skills/sdd/handoff-stale.sh" } ] }
    ]
  }
}
```

Если `~` в твоей сборке не раскрывается — путь абсолютный. Порог по умолчанию — три коммита, меняется переменной `SDD_HANDOFF_THRESHOLD`.

## Файлы

| Файл | Что внутри |
|---|---|
| `SKILL.md` | Конвейер: роли, десять шагов и что для каждого значит «готово» |
| `interview.md` | Как идёт раунд: вопросы с рекомендациями, простой язык, макеты, фоновое исследование |
| `coordinator.md` | Публикация тикетов, worktree, запуск, приём отчёта, слияние, обрыв исполнителя |
| `handoff.md` | Что лежит в документе передачи и когда он обновляется |
| `implement-agent-prompt.md` | Шаблон промпта исполнителя — самодостаточный, потому что исполнитель стартует с пустым контекстом |
| `handoff-stale.sh` | Тот самый хук |

## Что нужно

- Claude Code с плагином `mattpocock-skills`
- `git` — worktree здесь несущая конструкция, а не удобство
- `gh` (GitHub CLI), если нужна трекерная половина; без remote тикеты могут жить файлами
- Репозиторий, в который не жалко пустить агентов (они коммитят в свои ветки и никогда не пушат)

## Про язык

Инструкции скилла — по-русски. Это не недоделка: они писались и затачивались на том языке, на котором используются, а второй комплект процессного текста на полтысячи строк разошёлся бы с первым за недели. Claude исполняет их независимо от того, на каком языке говоришь с ним ты.

Нужен английский перевод — pull request с папкой `en/` принимается, с одной оговоркой: копия, которой перестанут пользоваться, со временем станет неверной.

## Откуда это взялось

Скилл вынут из настоящей вехи, а не придуман: двенадцать тикетов, четырнадцать фоновых агентов, десктопное приложение спроектировано, собрано и выпущено. Правила выше — цена того прогона. Для маленькой работы это дорого: правку в два файла делают без конвейера.
