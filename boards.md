# Доски проекта

Оператор видит работу глазами, а не в переписке (решение 17.10.2026). У каждого
проекта две доски, и обе обновляет координатор — не оператор.

## Задачи — GitHub Projects

Канбан над трекером. Второй список не ведётся: доска показывает те же issue.

- Один проект GitHub Projects на трекер, поле `Status`: **Идеи**, **Бэклог**,
  **В работе**, **Готово**. Встроенный порядок «закрыт → Готово» включён по
  умолчанию — проверить в **Workflows** проекта.
- Опубликовал спеку или тикет — добавь на доску:
  `gh project item-add <номер> --owner <владелец> --url <ссылка на issue>`,
  статус — **Бэклог** (идея без спеки — **Идеи**).
- Запустил исполнителя — **В работе**. Закрыл тикет с доказательствами — **Готово**
  само; не уехало — передвинь.
- Токену `gh` нужно право `project`: `gh auth refresh -h github.com -s project`
  (оператор, вход в браузере).

## Схемы — ExcaliDash

Свой сервер оператора: `https://draw.jedicoder.store` (ExcaliDash — Excalidraw с
папками). Ссылка на доску — `https://draw.jedicoder.store/editor/<id>`. Ключ API — `~/.config/excalidash/api-key` (права 600), заголовок
`Authorization: Bearer <ключ>`; ключ в переписку не печатать.

- **Проект — папка** (`POST /api/collections {"name": …}`), в ней доски:
  - **«<Проект> — разработка»**: «Где мы» (сделано → сейчас → дальше, с датами) и
    «Архитектура» (из чего проект состоит и как части связаны). Задач здесь нет —
    они на GitHub Projects.
  - **«<Проект> — бизнес»**: воронка, продукты, решения оператора с датами,
    открытые вопросы. Цены и сроки — только его словами.
  - **«<Проект> — контент»**: слева идеи, справа сценарии.
  Новая тема — раздел на доске, а не новая доска.
- Доска создаётся `POST /api/drawings {"name", "elements", "appState", "files",
  "collectionId"}`. **Правка — те же `id` фигур с бо́льшей `version`, удаление —
  `isDeleted: true`:** доска совместная, сервер сливает фигуры по `id`, и новый
  набор с новыми `id` ляжет поверх старого. После записи прочитай доску и сверь
  число живых фигур с задуманным.
- Своя отрисовка — не проверка: входа в редактор у агента нет. Не видел доску в
  редакторе — так и скажи оператору.

## Копия канбана на белой доске

Задачи правятся на GitHub Projects, а оператор смотрит проект на белой доске — поэтому на доске
«разработка» стоит раздел **«Задачи — канбан»**: те же четыре колонки, карточка на задачу (решение
оператора 18.10.2026: «помимо GitHub — дублировалось в белую доску»). Рисует его `board-sync.py`
из этой папки:

- настройка — `~/.config/board-sync.json`: `{ "<owner/repo>": { "owner", "project": <номер>, "board": "<id доски>" } }`;
- `board-sync.py <owner/repo>` или `--all`; `--dry` — только посчитать. Карточки закреплены за элементами
  проекта (стабильные `id` фигур с приставкой `kb<номер>-`): повтор обновляет раздел, лишнее помечается
  `isDeleted`, после записи число живых фигур сверяется; «Готово» — последние десять, остальные строкой;
- хук `board-sync-hook.sh` (PostToolUse на Bash в `~/.claude/settings.json`): после `gh issue
  create/close/reopen/edit` и `gh project item-…` через 15 с в фоне `--all`, журнал — `~/.cache/board-sync.log`.
  Правка статуса руками на сайте GitHub хук не будит — `board-sync.py --all` при следующем обновлении досок.
- Новый проект: доска GitHub Projects (статусы переименовать с сохранением `id` — встроенное «закрыт →
  Готово» продолжит работать; вид «Канбан» — мутацией `createProjectV2View`, `layout: BOARD_LAYOUT`) →
  строка в `~/.config/board-sync.json` → `board-sync.py <repo>`.

## Показать оператору — доской

Всё, что координатор показывает оператору картинкой, схемой или страницей (макеты,
варианты, разборы, сравнения), кладётся **доской в папку проекта в ExcaliDash** и
даётся ссылкой `https://draw.jedicoder.store/editor/<id доски>` (слово оператора
17.10.2026). Страницу claude.ai — только если доска не подходит (живой интерфейс,
таблица с данными); тогда ссылку на неё тоже положить на доску проекта.

## Когда обновлять

| Событие | Что сделать |
|---|---|
| Спека и тикеты опубликованы (шаг 5) | Тикеты на GitHub Projects — «Бэклог»; на доске разработки «Сейчас» — веха |
| Исполнитель запущен (шаг 7) | Тикет — «В работе» |
| Тикет влит и закрыт (шаг 8) | «Готово» проверить; «Где мы» — сделанное с датой |
| Выпуск (шаг 10) | «Где мы» — выпуск с версией; архитектура — если появилась новая часть |
| Решение оператора о деньгах или продукте | Доска бизнеса — строка с датой |
| Любое изменение задач на GitHub | Копия канбана — сама, хуком; правил статус на сайте — `board-sync.py --all` |
